# Privacy policy

*Last updated: 1 November 2026*

team-lead is a set of Markdown files: one skill, a kickoff template and two subagent definitions. It contains no code that runs on its own, makes no network requests and has no telemetry.

## What the author collects

Nothing. The author of team-lead doesn't receive, store or process any data from people who install or use it.

## Where your data does go

- **Claude Code and Anthropic.** When you use team-lead, Claude Code runs the instructions in these files. Your prompts, code and files are handled by Claude Code and Anthropic under [Anthropic's privacy policy](https://www.anthropic.com/legal/privacy), exactly as in any other Claude Code session. team-lead adds no other destination.
- **GitHub.** Installing team-lead downloads it from GitHub, and anything you post in this repository's issues is public. Both are covered by [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
